# AqylRoute AI — единый маршрут ребёнка с РАС

https://aqylroute.com

## Проблема

Помощь ребёнку с расстройством аутистического спектра раздроблена между здравоохранением, образованием и
социальной защитой. Родители сами ищут, куда идти дальше, по нескольку раз собирают одни и те же документы и
пропускают сроки, а специалисты каждого ведомства видят только свой фрагмент маршрута. В итоге ребёнок позже
получает помощь, а после 18 лет сопровождение и вовсе обрывается.

## Решение

Веб-приложение с двумя ролями — родитель и куратор:

1. **Анкета Q0 и интервью.** Родитель отмечает факты (заключение врача, ПМПК, справка МСЭ, документы на руках) и
   отвечает на 8–12 вопросов в чате. Какие вопросы задать, решает код по анкете; AI только формулирует их
   по-человечески. В конце — сводка «Правильно ли я понял?», которую родитель подтверждает или поправляет.
2. **Единый план.** Детерминированное ядро правил (`rules.py`) определяет, какие услуги нужны, какие заблокированы
   до выполнения других шагов или до даты и какие не нужны вовсе. AI пишет только объяснения и приоритет.
3. **Подтверждение куратором.** Куратор правит и подтверждает план; семья видит его только после подтверждения.
4. **Контроль сроков.** Сроки берутся из правил (окончание справки, возрастное окно скрининга, срок ПМПК). Код
   считает «скоро срок», просрочку и эскалацию, открывает заблокированные шаги и создаёт уведомления куратору и
   семье. Панель «Помощь семье» показывает чек-лист недостающих документов и готовый текст сообщения.
5. **Единая папка документов.** Документ отмечается один раз и учитывается во всех шагах и чек-листах.
6. **Передача дела.** Сводка по делу с этапом маршрута, выполненными, ожидающими и просроченными шагами,
   документами, препятствиями и покрытием по областям помощи. Сохраняется в PDF.

Три этапа маршрута: **раннее вмешательство** (до 3 лет), **коррекция** (3–7 лет), **социализация** (7–18 лет).

Принципы: **диагнозов не ставим** — инвалидность устанавливают не по диагнозу, а по степени ограничений
жизнедеятельности, поэтому план опирается на факты и документы; **шаги только из каталога услуг**;
**зависимости и сроки считает код**; **план подтверждает куратор**. Если модель недоступна, тот же план собирается
с шаблонными пояснениями.

Подробности (правила, роли, API, проверки) — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Демо

**Демо:** https://aqylroute.com

Три синтетических кейса — три этапа маршрута. Сценарий (около 60 секунд):

1. **Семья 2 (социализация).** Родитель → «Заполнить демо-ответами» → сводка → «Да, всё верно». Куратор видит план
   из трёх шагов: ПМПК и продление справки МСЭ просрочены (красным, эскалация), тьютор заблокирован до ПМПК.
   Куратор подтверждает, открывает «Помощь семье» — чек-лист документов.
2. Родитель отмечает «ПМПК пройдена» → шаг «Тьютор» открывается, куратору приходит уведомление.
3. **Семья 3 (коррекция).** Справка МСЭ действует до 10.11.2026: шаг продления «неактивен». Куратор нажимает
   «+14 дней» → шаг становится срочным, куратор и родитель получают уведомление, у родителя готовый чек-лист.
4. **Семья 1 (раннее вмешательство)** — словами: один активный шаг (педиатр), скрининг M-CHAT-R заблокирован до
   консультации.

## Запуск

Требования: Python 3.14.3, Node.js 26.9.0 (npm 11.19.1), GNU Make.

```bash
make install   # venv для backend, npm ci для frontend, .env из .env.example
make run       # backend на :8000, frontend на http://localhost:3000
make test      # pytest (35 тестов) + проверка типов TypeScript
```

Переменные окружения (файл `.env` в корне, значения не коммитятся):

| Переменная | Назначение |
|---|---|
| `OPENAI_API_KEY` | ключ OpenAI; без него работает демо-режим без модели (шаблонные вопросы, план по правилам) |
| `OPENAI_MODEL` | модель, по умолчанию `gpt-6-luna` |
| `OPENAI_BASE_URL` | необязательно, свой endpoint OpenAI-совместимого API |
| `DB_PATH` | путь к SQLite относительно `backend/`, по умолчанию `./data/app.db` |
| `ESCALATION_AFTER_DAYS` | через сколько дней просрочки шаг эскалируется, по умолчанию `3` |
| `DEMO_MODE` | `true` включает кнопки даты демо, демо-ответов и сброса |
| `PMPK_DUE_AFTER_DIAGNOSIS_DAYS` | необязательно: срок ПМПК после заключения врача, по умолчанию `365` (подтверждается) |
| `NEXT_PUBLIC_API_URL` | адрес API для браузера, по умолчанию `/api` (проксируется Next.js в FastAPI) |

Демо-режим: `DEMO_MODE=true`. Сброс данных — кнопка «Сбросить демо» на панели куратора или `make reset-db`
(база пересоздаётся из seed с двумя синтетическими кейсами при следующем запуске).

Проверка модели: `make eval` — 10 генераций плана для кейса 2 на реальной модели. Проверяется, что модель
возвращает валидный JSON ровно с набором шагов, который определил код, и без стоп-слов. Результат на `gpt-6-luna`
(30.09.2026): 10/10 — валидный JSON, набор шагов совпал с кодом, 0 предупреждений, fallback не понадобился; 7–11 секунд на план.

### Деплой на сервер (без Docker)

Сервер: Ubuntu 24.04, Python 3.12, Node.js 22, nginx, pm2; домен за Cloudflare. Файлы — в папке `deploy/`:

| Файл | Назначение |
|---|---|
| `deploy/deploy.sh` | обновление: `git pull`, зависимости, сборка фронтенда (standalone), перезапуск pm2, проверка |
| `deploy/ecosystem.config.js` | pm2: `aqyl-api` (uvicorn, один воркер на 127.0.0.1:8000) и `aqyl-web` (Next.js на 127.0.0.1:3000) |
| `deploy/nginx-aqylroute.conf` | nginx: прокси `aqylroute.com` → Next.js; `/api` Next.js проксирует в FastAPI |

Первый запуск на сервере:

```bash
git clone https://github.com/hackathonteamqaz/AqylRoute-AI.git /var/www/aqylroute
cd /var/www/aqylroute && cp .env.example .env   # заполнить OPENAI_API_KEY; файл не коммитится
./deploy/deploy.sh
cp deploy/nginx-aqylroute.conf /etc/nginx/sites-available/aqylroute
ln -s /etc/nginx/sites-available/aqylroute /etc/nginx/sites-enabled/ && nginx -t && systemctl reload nginx
pm2 startup systemd && pm2 save                  # автозапуск после перезагрузки
```

Обновление: `cd /var/www/aqylroute && ./deploy/deploy.sh`. HTTPS — сертификат Let's Encrypt (`certbot --nginx`) на
сервере и Cloudflare в режиме SSL Full (strict).

## Структура проекта

```
backend/                 FastAPI + SQLite
  app/rules.py           ядро плана: правила для каждой услуги (active / locked / hidden, сроки, зависимости)
  app/catalog.py         seed: справочник из 18 услуг, 15 типов документов, 12 вопросов, 3 синтетических кейса
  app/interview.py       интервью по слотам и сводка «Правильно ли я понял?»
  app/plan.py            генерация плана: набор из правил, тексты от AI, валидация и fallback
  app/tracking.py        разблокировка, сроки, эскалация, уведомления, «Помощь семье»
  app/handoff.py         «Передача дела»
  app/llm.py             клиент OpenAI (structured outputs, запасной JSON-режим)
  app/safety.py          проверка стоп-слов (список в app/config.py)
  app/main.py            REST API
  tests/                 pytest: эталоны трёх кейсов и приёмочные тесты
  scripts/eval_plan.py   проверка генерации на реальной модели
frontend/                Next.js (TypeScript)
  app/parent/            кабинет родителя: анкета Q0, интервью, «План», «Напоминания», «Документы»
  app/curator/           дела и сроки, уведомления, карточка дела, «Передача дела»
  app/api/[...path]/     прокси /api → FastAPI
  components/, lib/      каркас (боковая панель, шапка), карточка шага, «Помощь семье», папка документов, типы, API
                         дизайн по прототипу команды: светлая тема, шрифт Onest, акцент #16615C
deploy/                  деплой на сервер: скрипт обновления, pm2, nginx
docs/                    архитектура и скриншоты
Makefile, dev.sh         установка, запуск, тесты
```

## Что готово

- [x] Роли родитель и куратор без паролей, выбор на входной странице
- [x] Анкета Q0 (факты без диагнозов) и три синтетических кейса — три этапа маршрута
- [x] Интервью по 12 слотам с условиями в коде (кейсы: 8, 11, 11 вопросов), кнопка «Заполнить демо-ответами»
- [x] Сводка «Правильно ли я понял?» с правкой; план — только после подтверждения
- [x] Ядро правил: активные, заблокированные (зависимости и дата открытия) и скрытые шаги; сроки по правилам
- [x] AI (OpenAI structured outputs) пишет объяснения; лишний шаг от модели → fallback с тем же набором
- [x] Подтверждение и правка плана куратором; родитель не видит план до подтверждения
- [x] «Скоро срок», просрочка, эскалация; уведомления куратору и семье без дублей; дата демо (+1 / +7 / +14)
- [x] Красные флаги: алерт куратору и фиксированный текст семье
- [x] Панель «Помощь семье»: чек-лист документов, как подать, шаблон сообщения, черновик письма ведомству
- [x] Единая папка документов: отметка один раз — обновляются все шаги
- [x] «Передача дела» с этапом маршрута и сохранением в PDF, только для куратора
- [x] 35 автотестов, включая эталонные планы трёх кейсов
- [x] Сервер развёрнут (Hetzner, pm2 + nginx, домен aqylroute.com за Cloudflare)
- [x] HTTPS: https://aqylroute.com (Let's Encrypt с автопродлением, Cloudflare Full strict)
- [ ] Справочная карточка «виды помощи», медицинская реабилитация, поиск организаций, казахский язык, паспорт ребёнка (P2)

Ограничения: данные только синтетические; справочник услуг неполный, правила и сроки (например, срок ПМПК после
заключения) нужно подтвердить по официальным источникам; ссылки на eGov не заполнены до проверки; суммы пособий не
указываются; нет интеграции с chis.kz и ПМПК; уведомления не отправляются во внешние каналы (только в кабинете);
авторизации нет — это демо.
